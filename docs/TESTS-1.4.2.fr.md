# Scénarios de test — DJSync 1.4.2

Lot 1 de la 1.4.2, « prête pour la vidéo » : tout ce qui change l'interface. Numérotation : thème en 3 lettres + n°
(voir `revues/numerotation-tests.md`) ; dans le suivi : « 142 · NAV-1 ». Rangés par bloc, pour tester en plusieurs fois.
Le lot 2 (C24 clé vierge, C23 transferts en lot) a ses scénarios avant les tests automatiques (VIE, TRA, PLA-2 à 4). Le lot 3 (retours de la 1.4.1) est en fin de fichier, puis le lot Opus (B102, B103, C198 et fiches A2 de l'audit UX), puis la **rc.2** (audits A1, A3, A6, retours des testeurs, tests KO de la rc1).
